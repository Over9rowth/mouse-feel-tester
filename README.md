# 鼠标手感仪（MouseFeelTester）

> **外设轨迹动力学体检台：最小二乘圆拟合量化径向微抖动、急停过冲与回报率间隔稳定性**  
> 一套 100% 本机离线运行的外设物理性能客观观测仪器。

---

## 它是什么

鼠标手感仪通过对画圆、直线甩枪、跟点三项标准化实验轨迹的高精度时间戳采样，利用经典数学物理模型对传感器与鼠标垫物理手感进行量化：

- **Kåsa 代数最小二乘圆拟合**：解线性方程组自适应拟合圆心 $(c_x, c_y)$ 与半径 $R$，绝不假设固定原点；
- **径向微抖动与顿挫提取**：
  - 计算每一点的径向残差 $e_i = r_i - R$；
  - 动态窗口移动平均分离手部椭圆偏心趋势，提取真正由传感器颗粒感与垫子阻尼造成的高频抖动 RMS；
  - 统计超过 $\pm 2.0\text{ px}$ 的顿挫极值点及角度分布；
- **直线甩枪急停量化**：
  - 沿两点目标连线主轴计算投影距离与垂直横向偏离度；
  - 精确测量超调过冲量（$\text{Overshoot px}$）与回拉修正稳定耗时（$\text{ms}$）；
- **回报率与时间间隔稳定性**：统计相邻事件采样间隔 $\Delta t$、估算真实刷新率（Hz）并捕获丢包卡顿跳变。

---

## 它不是什么

- **它不是主观玄学玄谈**：所有数据均来自真实坐标与时间戳采样计算，不虚构评测分数；
- **它不是云端遥测工具**：100% 本机离线运行，不上传任何轨迹或鼠标输入数据；
- **它不是游戏作弊宏或驱动插件**：纯物理轨迹观测与度量台。
